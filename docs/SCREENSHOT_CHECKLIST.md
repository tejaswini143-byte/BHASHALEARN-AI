# Screenshot checklist

Capture only with synthetic student data. Keep one unmodified PNG per item and note the commit and environment (mock/live) in its filename or submission log. The checklist is a capture plan; no screenshots are represented as captured by this task.

- [ ] Landing page showing bilingual positioning and main learning paths.
- [ ] Registration form with synthetic details obscured where appropriate.
- [ ] Dashboard with an empty-state account, showing no fabricated learner metrics.
- [ ] Classroom session with a Telugu + English question, reply, and saved history. Mark mock output.
- [ ] Voice tutor transcript review and playback controls. Mark whether provider output is mocked or live.
- [ ] Teacher preview with animation/expression/board-position controls. Mark synthetic viseme demo if used.
- [ ] PDF page extraction before indexing, then an explicit indexed status.
- [ ] PDF semantic search result showing document title, page number, and similarity. Mark mock result if used.
- [ ] Quiz result with score, explanation, and next recommendation.
- [ ] Analytics trend/range view with evidence labels and any “not recorded” measure visible.
- [ ] Future Me scenario branch and completion screen with its non-predictive disclaimer visible.
- [ ] Research/assistant conversation showing citations or saved message history where available.
- [ ] Mobile-width classroom or analytics view to demonstrate responsive controls.
- [ ] Test report summary containing pass/fail/skip counts; do not crop away skipped cases or environment labels.
