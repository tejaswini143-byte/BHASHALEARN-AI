# Demo video script (about 4 minutes)

Use a synthetic student and synthetic learning material. Label any provider mock on screen. Do not show API keys, real student information, or private speech recordings.

| Time | Screen / action | Narration |
| --- | --- | --- |
| 0:00–0:20 | Landing page; point out Telugu + English positioning | “BHASHALEARN AI brings classroom chat, voice, visual lessons and progress into one learning workspace.” |
| 0:20–0:45 | Register a synthetic learner, then dashboard | “A learner creates an account and opens a private dashboard. This capture uses a test account.” |
| 0:45–1:25 | Start a classroom session on fractions; ask one mixed-language question | “The student asks in Telugu and English. The session retains the question and answer as shared learning context.” If using a mock, say: “This answer is supplied by the labeled QA mock.” |
| 1:25–1:55 | Open the voice tutor; show listen/replay, pause/stop and transcript review | “The voice flow lets the learner review a transcript and replay tutor speech. Live Gnani behavior is shown only if this recording uses a separately verified live environment.” |
| 1:55–2:30 | Upload synthetic PDF, show extracted pages, explicitly index, run search and open cited page | “PDF text is extracted locally. Indexing and semantic lookup are explicit actions, and results include the source document and page.” |
| 2:30–3:00 | Start and submit a quiz | “Objective practice returns a score and explanation, then makes progress evidence available to analytics.” |
| 3:00–3:25 | Analytics page and range selection | “Analytics displays recorded activity and distinguishes unavailable or unrecorded measures from zero.” |
| 3:25–3:50 | Future Me branching career scenario; teacher preview controls | “The career scenario is a deterministic reflection exercise, not a prediction. The teacher preview exposes its supported animation and board controls.” |
| 3:50–4:00 | End card with verification note | “This demo covers the flows shown. Provider-backed features require separate live acceptance evidence.” |

## Capture notes

- Record browser version, commit hash, environment type (mock or live), and date in the submission notes.
- If the database-backed route is used, verify the dedicated E2E database and storage directory first.
- Do not call mock-provider output “Gnani speech,” “Gemini response,” or a live provider result.
